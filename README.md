# Aplikasi SPK Fuzzy AHP Flask

Versi ini menggunakan Flask, bukan Streamlit. Fitur utama:

- Login dan daftar akun
- Input kriteria
- Input alternatif per kriteria
- Validasi CR <= 0.10
- Perhitungan Fuzzy AHP dengan synthetic extent dan defuzzifikasi centroid
- Sintesis bobot global
- KMeans untuk level prioritas
- Riwayat pekerjaan
- Unduh laporan PDF
- Tombol Lihat/Sembunyi password

## Cara menjalankan

```powershell
cd D:\fahp_fiks\flask_fahp_app_professional
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Buka browser:

```text
http://127.0.0.1:5000
```

Jika tampilan belum berubah, tekan `Ctrl + F5` di browser untuk hard refresh.
